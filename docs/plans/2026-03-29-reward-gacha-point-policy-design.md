# 리워드 가챠 포인트 지급/적립 정책 디자인

## 문서 범위

이 문서는 리워드 가챠에 사용하는 **포인트 지급 방식과 적립 정책**만 정의한다.

이 문서에서 확정하는 범위는 아래와 같다.

- 포인트의 기본 성격
- 포인트 획득원
- 일반 러닝 지급 규칙
- 주간 스트릭 지급 규칙
- 고스트 모드 승리 지급 규칙
- 중복 누적 가능 여부

이 문서는 아래 항목은 아직 확정하지 않는다.

- 포인트 저장용 DB 스키마 상세
- 포인트 지급/차감 API 명세
- 중복 지급 방지의 구현 방식
- 주간 기준일과 정확한 집계 타이밍
- 화면 UI 문구 및 노출 방식

## 전제

- 선행 문서에서 합의된 리워드 가챠의 제품 방향은 유지한다.
- 가챠 포인트는 복잡한 투자형 재화가 아니라, 러닝 경험에 자연스럽게 연결되는 보상 재화로 본다.
- 사용자가 규칙을 외우지 않아도 될 정도로 단순한 지급 구조를 우선한다.
- 포인트는 “얼마나 오래 쌓아두는가”보다 “러닝과 도전의 결과로 자연스럽게 얻고 쓰는가”에 초점을 둔다.

## 정책 목표

이 포인트 정책의 목표는 아래와 같다.

- 러닝을 실제로 한 사용자에게만 보상이 주어지게 한다.
- 규칙을 단순하게 유지해 사용자가 “오늘 포인트를 받을 수 있는지” 바로 이해할 수 있게 한다.
- 짧은 악용 플레이를 막되, 과도하게 복잡한 차등 보상 구조는 만들지 않는다.
- 일반 러닝, 스트릭, 경쟁형 모드가 서로 다른 동기로 포인트를 주되 한 시스템 안에서 자연스럽게 누적되게 한다.

## 기본 원칙

- 포인트는 **소멸되지 않는다.**
- 포인트에는 **이월 제한이 없다.**
- 포인트는 여러 획득원에서 **독립적으로 누적될 수 있다.**
- 한 획득원에서의 지급 조건 충족은 다른 획득원의 지급 여부를 막지 않는다.
- 포인트 지급 규칙은 가능한 한 **정적이고 설명 가능한 규칙**으로 유지한다.

## 포인트 획득원

현재 단계에서 포인트 획득원은 아래 세 가지로 정의한다.

1. 일반 러닝
2. 주간 스트릭
3. 고스트 모드 승리

이 세 획득원은 서로 독립적으로 동작한다.

즉, 사용자는 같은 날 일반 러닝 보상을 받고,
고스트 모드 승리 보상을 추가로 받을 수 있으며,
같은 주 안에서 스트릭 마일스톤 보상도 별도로 누적할 수 있다.

## 일반 러닝 지급 규칙

- 일반 러닝 보상은 **하루 누적 러닝 거리**를 기준으로 판단한다.
- 사용자가 **하루 동안 누적 1km 이상 러닝**하면, 그날의 일반 러닝 보상 조건을 충족한 것으로 본다.
- 일반 러닝 보상은 **하루 1포인트 고정 지급**으로 운영한다.
- 같은 날 누적 거리가 2km, 3km, 10km가 되어도 일반 러닝 보상은 **추가로 늘어나지 않는다.**
- 즉, 일반 러닝 보상은 거리 비례형이 아니라 **일일 달성형 보상**이다.

이 규칙의 목적은 사용자가 “오늘 최소 기준을 달성했는지”만 이해하면 되게 하는 데 있다.
복잡한 거리 구간별 차등 보상은 현재 단계에서 포함하지 않는다.

## 주간 스트릭 지급 규칙

- 주간 스트릭은 **해당 주 안에서 연속으로 러닝한 일수**를 기준으로 본다.
- 주간 스트릭 보상은 **3일, 5일, 7일** 달성 시점마다 지급한다.
- 각 마일스톤마다 **1포인트씩 추가 지급**한다.
- 따라서 한 주에 7일 스트릭을 완성하면, 스트릭 보상으로는 **총 3포인트**를 받을 수 있다.
- 같은 주 안에서 같은 스트릭 마일스톤 보상은 **1회만 지급**한다.

이 구조는 매일 러닝하도록 유도하면서도,
하나의 긴 스트릭 달성 경험이 단계적으로 보상되도록 만들기 위한 것이다.

## 고스트 모드 승리 지급 규칙

- 고스트 모드에서는 **승리할 때마다 1포인트를 지급**한다.
- 이 보상은 일반 러닝의 일일 달성 보상과는 **별도 획득원**으로 본다.
- 따라서 같은 날 이미 일반 러닝 보상을 받았더라도, 고스트 모드에서 승리하면 **추가로 1포인트를 더 받을 수 있다.**
- 현재 단계에서는 난이도, 시간, 점수, 거리 차이에 따른 **차등 보상은 두지 않는다.**
- 현재 규칙에서 고스트 모드 포인트 지급의 판단 기준은 **승리 여부 자체**다.

이 규칙은 경쟁형 모드의 성취를 직관적으로 보상하기 위한 것이다.
복잡한 성과 계산식보다, 사용자가 “이기면 1포인트”를 즉시 이해하게 하는 것을 우선한다.

## 지급 구조 요약

- 일반 러닝: 하루 누적 1km 이상 달성 시 **1포인트**
- 주간 스트릭: **3일 / 5일 / 7일** 달성 시점마다 **각 1포인트**
- 고스트 모드 승리: **승리 1회당 1포인트**
- 포인트는 **소멸되지 않으며**, **이월 제한도 없다.**
- 각 획득원은 **독립적으로 누적 가능**하다.

## 예시 시나리오

### 예시 1. 일반 러닝만 한 경우

- 사용자가 하루 동안 총 1.2km를 뛰었다.
- 그날 고스트 모드 승리는 없고, 스트릭 마일스톤도 달성하지 않았다.
- 이 경우 사용자는 **일반 러닝 보상 1포인트**를 받는다.

### 예시 2. 같은 날 더 많이 뛰었지만 일반 러닝 보상은 그대로인 경우

- 사용자가 하루 동안 총 4.8km를 뛰었다.
- 일반 러닝 기준은 이미 충족했으므로, 그날 일반 러닝 보상은 **1포인트**다.
- 추가 거리만으로 일반 러닝 보상이 2포인트, 3포인트로 늘어나지는 않는다.

### 예시 3. 주간 스트릭과 함께 받은 경우

- 사용자가 해당 주의 연속 러닝 3일차를 달성했다.
- 그날 하루 누적 러닝 거리도 1km 이상이다.
- 이 경우 사용자는 **일반 러닝 보상 1포인트 + 3일 스트릭 보상 1포인트**로 총 **2포인트**를 받는다.

### 예시 4. 고스트 승리를 함께 달성한 경우

- 사용자가 하루 누적 1km 이상을 달성했다.
- 같은 날 고스트 모드에서 2번 승리했다.
- 이 경우 사용자는 **일반 러닝 보상 1포인트 + 고스트 승리 보상 2포인트**로 총 **3포인트**를 받는다.

### 예시 5. 한 주에 7일 스트릭을 완성한 경우

- 사용자가 한 주 안에서 7일 연속 러닝을 달성했다.
- 스트릭 보상은 3일차, 5일차, 7일차에 각각 지급된다.
- 따라서 해당 주의 스트릭 보상 총합은 **3포인트**다.

## 현재 합의 요약

- 가챠 포인트는 소멸되지 않는다.
- 가챠 포인트에는 이월 제한이 없다.
- 포인트 획득원은 일반 러닝, 주간 스트릭, 고스트 모드 승리다.
- 일반 러닝 보상은 하루 누적 러닝 거리 1km 이상 달성 시 1포인트다.
- 같은 날 추가 거리로 일반 러닝 포인트가 더 늘어나지 않는다.
- 주간 스트릭 보상은 3일, 5일, 7일 달성 시점마다 각각 1포인트다.
- 같은 주 안에서 같은 스트릭 마일스톤은 중복 지급하지 않는다.
- 고스트 모드 승리 보상은 승리 1회당 1포인트다.
- 고스트 모드 보상은 일반 러닝 보상과 별도로 누적된다.
- 현재 단계에서는 거리 비례, 난이도 비례, 시간 비례 차등 지급을 두지 않는다.
